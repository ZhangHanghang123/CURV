5核心拟合模型（Nelson-Siegel 系列）

平台内置 Nelson-Siegel 与 Svensson 两套参数化拟合模型，参数经济含义明确（β0 水平 / β1 斜率 / β2 曲率），是利率风险计量与情景模拟的事实标准。

R(t) = β0 + β1 · [(1-exp(-t/τ)) / (t/τ)] + β2 · [(1-exp(-t/τ)) / (t/τ) - exp(-t/τ)]       —— Nelson-Siegel (1987) R(t)_NSS = R(t) + β3 · [(1-exp(-t/τ₂)) / (t/τ₂) - exp(-t/τ₂)]       —— Svensson (1994, 增加一个曲率项)
参数经济含义业务用途
β0长期利率水平（曲线渐近线）判断利率中枢
β1斜率（短端溢价）判断曲线陡峭/平坦化
β2中段曲率判断曲线弯曲程度
β3第二曲率（NSS 独有）拟合更复杂的曲线形态
τ曲率衰减参数控制 β1/β2 影响范围

✅ 验收标准：常规市场环境拟合 RMSE ≤ 2bp；拟合参数以时序存储，可独立查询分析（如 β1 时序判断曲线陡峭化趋势）。

10风险与开放问题

⚠️ 外部依赖风险
中债/外汇接口授权周期长；SSO 需 IT 配合；资产负债数据来自 ALMT；DeepSeek 服务稳定性需 fallback
🔧 技术风险
拟合精度 ≥2bp 阈值可能不覆盖波动大的品种；时序数据量爆炸需分区压缩；多源数据口径差异需统一标准化层；智能对话幻觉需强制引用数据源
开放问题建议
拟合精度 2bp 是否覆盖所有曲线？多算法并行 + 人工调参 + 业务确认阈值
资产负债组合数据来源？建议对接 ALMT
三期 ML 模型纳入与否？取决于数据积累情况
多币种支持优先级？一期仅人民币，二期评估
实时曲线（盘中）？一期仅日终，盘中增量二期
